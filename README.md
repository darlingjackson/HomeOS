HomeOS ✦

A smarter, calmer way to run home.

HomeOS is my personal household management app — built to keep the everyday stuff in one place without making home feel like another job. 🤍

It started as a cleaning system and slowly grew into something much bigger.

What it handles

✦ Daily routines and household tasks

🧼 Cleaning by room or zone

🧺 Laundry tracking

🛒 Inventory + shopping

📅 Family calendar

🚀 Kids Mode with age-based missions

🍂 Seasonal cleaning + home care

🏡 Household setup, people and permissions

Built with

HTML

CSS

Vanilla JavaScript

Supabase

GitHub Pages

Processing.js for the Rhythm Companion

I’m intentionally keeping the stack simple. If HomeOS can do something without adding another framework, that is usually the route I want to take.

How I’m building it

I’m cleaning and improving HomeOS one feature at a time:

feature → dependencies → frontend + database → cleanup → test

The goal is to keep the code easy to understand, avoid duplicate logic, and make sure every feature actually earns its place.

The idea behind HomeOS

I don’t want HomeOS to be another app that just gives you more things to check off.

I want it to help carry some of the mental load of running a home — what needs attention, what is already handled, what the kids are responsible for, what is running low, and what can wait.

Basically, I keep looking around my house and thinking:

“HomeOS should know how to do that.”

So I build it. ✦

HomeOS is still growing — one useful feature at a time.
